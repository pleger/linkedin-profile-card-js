LinkedIn Profile Card · v2.0.0

Una tarjeta configurable para enlazar un perfil de LinkedIn. No utiliza la API ni el badge oficial. Los nombres y enlaces de este ejemplo son ilustrativos.

1. SVG geométrico incorporado data-background="geometric"

2. Blanco data-background="white"

3. Transparente data-background="transparent"

4. Color sólido data-background="color"

5. SVG propio data-background="svg"

Componente independiente de LinkedIn. Personaliza nombre, cargo, afiliación, URL y colores antes de publicarlo.
